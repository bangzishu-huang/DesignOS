# DesignOS
A unique webOS version of my design portfolio I will be making! A twist to the traditional portfolios...

This idea originally sprouted when I was looking at other people's design portfolios and I slowly realized that it all felt very similar. They usually rely on some website builders such as Wix or Squarespace, giving a very "normal" vibe to it. I wanted to make a portfolio that would be able to stand out against the talented designers around me. I thought to build DesignOS because while I was brainstorming I remembered one of my projects where I created my own operating system. So, I thought it would be a very unique twist to make my portfolio like an OS, but of course also make a normal portfolio for the recruiters that value speed and time when reviewing.

Throughout the process of designing this OS, I had to learn a lot from the coding languages. Some notable complex parts were learning how to implement z-indexing and also make the windows on the OS part draggable. There were lots of iterations of the initial versions of the portfolio in order to figure out what projects to include and the placement of a lot of objects. This was a huge learning experience for me, as I was able to develop my technical skills further, even through the process of debugging (which took really long).

AI Used None

# Tech Slack
- Frontend: JavaScript, HTML, CSS
- Hosting: GitHub Pages
- Version Control: GitHub
- Development Tools: Visual Studio Code, Live Server Extension

# Features
- Z indexing implemented for windows in order to get the layering feature
- Windows in the OS are also draggable
- Created tab like functions for each category of projects on the OS
- Seamless switching between the OS and the normal portfolio
- Subtle animations, such as hover, in order to enhance the user experience
- Custom favicon and interface designed uniquely for DesignOS
